📚 Library Tracker – DSA C++ Course Project (Cipher School) 

---

This project is a console-based Library Tracker system developed as part of the DSA with C++ course offered by Cipher School. It focuses on applying Object-Oriented Programming (OOP) and basic Data Structures like vectors to simulate a real-world library system

---

📌 Project Overview

---

The Library Tracker allows users to:

Add books with title and author

Borrow and return books

View all available and borrowed books

Navigate the system using a user-friendly, menu-driven interface

It provides hands-on experience with vectors, classes, control flow, and modular code design — ideal for students learning DSA in C++.

---

✅ Features

---

➕ Add new books to the library

🔁 Borrow books by index

♻️ Return borrowed books

📚 View all books with current availability

🧾 List only the borrowed books

🖥️ Interactive menu-based CLI

---

📘 Data Structures & Concepts Used

---

Vectors (STL) – dynamic array to store book entries

Classes & Objects – for modeling Books and Library

Encapsulation – to manage data access

Conditionals & Loops – to drive program logic

Menu-based user interaction
